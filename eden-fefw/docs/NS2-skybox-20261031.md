# Skybox geometry correction (2026-10-31)

Fortune's Weave displayed a flat sky in the first dialogue scene and in battles.
The cloud texture was present, but the native vertex shader's floating selects
lost their source negations during lowering. The cube's procedurally generated
vertices all landed on the same positive corner, leaving no sky geometry to draw.

The lowering now applies FSEL absolute-value and negation modifiers by default.
Integer SEL remains bitwise. `EDEN_NATIVE_LOWER_DISABLE=audit_fsel` retains the
previous behavior for diagnostic comparisons. The native translator salt also
advances; corrected lowered programs receive different shader hashes.

Validation:

- MSVC GUI and CLI builds completed successfully.
- An independent evaluator ran 1,728 checks of the emitted Maxwell instructions,
  covering source forms, modifiers, predicates and register aliases. The previous
  lowering failed 816 checks; the correction passed all checks.
- Emulator frame captures of the first dialogue show sky detail after the change.
  The cloud texture read back from the GPU is byte-identical before and after.
- A subsequent launch with the existing shader cache loaded the battle save and
  rendered at 30 fps. Its sky draw used the same corrected vertex shader and
  unchanged pixel shader as the opening scene.
- Synthetic Catch2 regression cases cover all eight cube corners and source
  modifiers across source forms and aliases. The Windows build has no unit-test
  target, so these Catch2 cases and the full suite have not been run here.

Runs used isolated save copies and bounded termination. They establish rendering
behavior, not clean shutdown or compatibility with other games.
